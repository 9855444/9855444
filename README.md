## 关于我

我是 **AI 机器视觉方向的在校学生**，正在把「成像 → 算法 → 部署」这条链路系统地学一遍、做一遍。

- **在学**：深度学习基础、目标检测与分割、相机标定与 3D 视觉
- **在做**：课程项目、论文复现、工业缺陷检测的小型实验
- **在补**：C++ / CUDA 工程能力，以及模型量化与推理加速
- **目标**：毕业时能独立完成一个从数据到上线的视觉项目

> 先把一个项目做完整，再谈做很多个项目。
